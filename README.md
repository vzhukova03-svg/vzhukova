# Viktoriia OS — public source export

Ukrainian grayscale planning interface with Home, Plan, Goals and Inbox.

This export contains no personal Q4 seed content, Site credentials, Site IDs or Git history. The private working Site is unchanged.

## Run locally

Serve the dist directory with a local web server and open index.html.

## Current limitations

User-entered data is still stored only in that browser. This export does not implement cloud sync and does not update the existing ChatGPT Site automatically.

Both day and week use 1–3–5. Planning status controls are removed. Enter saves the current task and focuses the next available slot.
